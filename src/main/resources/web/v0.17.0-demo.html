GlobalDir 跨项目共享 + Archive 归档

对标 Reasonix store.go — user/feedback 类型记忆自动路由到 ~/.anima/memory/global/，跨项目共享。
Archive：forget 时不再直接删除，而是移到 .archive/ 目录带时间戳，可追溯恢复。

记忆路由规则: ┌─────────────────────────────────────┐ │ remember({ type: "user" }) │ │ remember({ type: "feedback" }) │────→ ~/.anima/memory/global/ (所有项目共享) └─────────────────────────────────────┘ ┌─────────────────────────────────────┐ │ remember({ type: "project" }) │ │ remember({ type: "reference" }) │────→ .anima/memory/ (项目本地) └─────────────────────────────────────┘ 归档机制: forget("password-storage-strategy") → .anima/memory/.archive/2026-06-29-09-30-00-password-storage-strategy.md (文件保留、MEMORY.md 索引清理、可手动恢复)

祖先链发现 + AGENTS.md/CLAUDE.md 兼容 + 用户全局记忆

对标 Reasonix doc.go — 从 cwd 向上遍历到 .git 根目录，加载所有 ANIMA.md / AGENTS.md / CLAUDE.md / REASONIX.md。
支持 ~/.anima/ANIMA.md 用户全局记忆 + ~/.anima/AGENTS.md 跨工具兼容。

记忆加载层级 (低→高优先级): 1. ~/.anima/ANIMA.md [user] 用户全局，跨项目共享 2. ~/.anima/AGENTS.md [user] AGENTS.md 兼容 3. /monorepo/ANIMA.md [ancestor] 仓库根 .git 所在目录 4. /monorepo/subproject/ANIMA.md [project] 项目根 (cwd) 5. ./ANIMA.local.md [local] 个人覆盖 (git-ignored) 6. ./AGENTS.local.md [local] Claude 兼容覆盖 @import 递归: 最多 5 层，支持 ~ 展开，带循环检测 兼容格式: ANIMA.md, AGENTS.md, CLAUDE.md, REASONIX.md (全部自动识别)
