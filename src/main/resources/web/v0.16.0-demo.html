双模型协作 (Coordinator)

当配置了多个 provider（如 flash + pro），自动启用双模型模式。
Planner (pro) 用只读工具分析任务产出计划 → Executor (flash) 接收计划并执行。两个模型独立会话，互不干扰 DeepSeek 缓存。

用户输入
"实现 JWT 认证"
→
Planner (pro)
产出计划
→
Executor (flash)
执行任务

Goal 自主模式 (Goal Machine)

FSM 驱动的长周期自主任务。最多 50 轮自动延续，检测空闲/阻塞。支持 [goal:complete] / [goal:blocked] 信号。

并行任务分发 (Parallel Tasks)

支持依赖图 (DAG) 的多子 agent 并发执行。结果自动汇总，前序任务产出通过文件传递给后续任务。

模型调用 — parallel_tasks
模型调用 parallel_tasks({ tasks: [ { prompt: "审查 AuthController 安全性", description: "auth-audit" }, { prompt: "审查 UserController 安全性", description: "user-audit" }, { prompt: "汇总前面两个审查结果并生成报告", description: "report", depends_on: [0, 1] } ] }) ⎿ task/sub-1 auth-audit → 正在运行… ⎿ task/sub-2 user-audit → 正在运行… (auth-audit 和 user-audit 并发执行) ⎿ task/sub-2 user-audit → ✓ 完成 ⎿ task/sub-1 auth-audit → ✓ 完成 ⎿ task/sub-3 report → 正在运行… (等待 depends_on 完成) ⎿ task/sub-3 report → ✓ 完成 Completed 3 parallel tasks: ── auth-audit ── 发现 CSRF 缺失 + 输入未校验，共 3 处风险 ── user-audit ── 密码存储未加盐，建议使用 BCrypt ── report ── 综合审查报告： • AuthController: CSRF 缺失（高危）、输入未校验（中危） • UserController: 密码未加盐（高危） 建议优先修复：添加 CSRF token → 密码 BCrypt → 输入校验

BM25 历史搜索 (History Search)

轻量级 BM25 全文检索（无外部依赖），索引所有 .jsonl 会话文件。
支持 search 和 around 两种操作，让模型能查询历史决策和命令。
