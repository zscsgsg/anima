🔄 Mid-turn Steer — 运行中注入指导

🎯 使用场景

Agent 正在执行长任务（如多次工具调用），用户发现方向不对，可以直接用 !消息 注入纠偏指令，而不是等它完成后重新提问。

> 帮我在整个项目中找到所有使用 Thread.sleep 的地方并替换为优雅方案 ➤ 正在分析项目结构...我先用 grep 搜索 Thread.sleep 出现位置... ⏺ grep(pattern="Thread\.sleep") ⎿ src/main/java/com/anima/agent/AgentLoop.java:238 ⎿ src/main/java/com/anima/terminal/TerminalUI.java:150 ⎿ src/test/java/com/anima/AgentTest.java:45 ! 先列出文件，不要直接改 — 我还想确认一下范围 ⎿ Steer queued: 先列出文件，不要直接改 — 我还想确认一下范围 ➤ [收到用户中途指导] 改为先读取文件确认范围... ⏺ read_file(path="src/main/java/com/anima/agent/AgentLoop.java", offset=230, limit=20) ⎿ 238→ try { latch.await(); } catch (InterruptedException e) { ⎿ 239→ Thread.currentThread().interrupt(); break; ⎿ 240→ }

⚙️ 工作原理

  • Steer 消息被加入队列（线程安全），下一轮 loop 迭代消费
  • 注入到 session 时带 [Mid-turn steer from user] 前缀标记
  • 模型视其为当前任务的引导，而非新任务
  • 终端以 !消息 触发，空 steer 不发送

🪝 Hooks 系统 — 生命周期钩子

📄 配置文件示例：.anima/settings.json

{ "hooks": { "PreToolUse": [ { // 在执行任何 bash 命令前，先运行安全检查脚本 "match": "bash", "command": "echo 'check passed' && exit 0", "timeout": 5000 }, { // 阻止危险的 rm -rf 命令 "match": "bash", "command": "echo 'blocked: dangerous command' && exit 2" } ], "PostToolUse": [ { // 每次文件编辑后记录日志 "match": "edit_file|write_file|multi_edit", "command": "echo \"$(date): edited\" >> .anima/edit-log.txt" } ], "Stop": [ { // 每次 turn 结束时通知 "command": "echo 'Turn completed at' $(date)" } ] } }

文件位置：项目根目录 .anima/settings.json（项目级）或 ~/.anima/settings.json（全局级）

🎯 4 种事件类型

事件 触发时机 能否阻断 默认超时
PreToolUse 工具执行前 ✅ exit 2 = block 5s
PostToolUse 工具执行后 ❌ 仅记录 5s
UserPromptSubmit 用户提交消息时 ❌ 仅记录 5s
Stop Turn 完成时 ❌ 仅记录 5s

🤖 Subagents — task 工具

🎯 核心概念

模型调用 task 工具时，Anima 创建一个独立的子 Agent：

  • 子 Agent 拥有独立的 session（不污染父上下文）
  • 工具注册表自动过滤：排除 task 自身（防止递归）、排除 skill 工具
  • 子 Agent 的 thinking / 工具调用 不展示给用户
  • 仅最终答案返回给父 Agent

📋 task 工具 Schema

{ "prompt": "找到项目中所有调用 Thread.sleep 的位置并汇总", "description": "查找 Thread.sleep 用法", "tools": ["grep", "read_file"], // 可选：工具白名单 "max_steps": 5, // 可选：步数上限 "model": "pro" // 可选：模型覆盖 }

⛈️ Storm Breaker & Repeat Guard

🎯 两种防护

机制 检测条件 响应
Storm Breaker 连续 3 次相同工具 + 相同错误模式 自动注入："你已连续失败 3 次，改变策略"
Repeat Guard 同一工具在同一 turn 内成功 5 次 自动注入："你已成功调用 X 5 次，进入下一步"
Output Cap 工具输出超过 32KB 自动截断 + 尾部标记 "...（truncated N bytes）"

🧪 错误签名算法

剥离数字和十六进制地址后比较，避免变量部分干扰匹配：
"Error at line 42" → "Error at line N"
"File not found: /tmp/abc123" → "File not found: /tmp/abcN"
