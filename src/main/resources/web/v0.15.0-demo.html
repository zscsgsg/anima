❓ Ask 工具 NEW

结构化多选题交互。1-4 题可选，支持多选。headless 运行时自动提供 fallback 决策建议。

askAskQuestionAskAnswer

🧠 Remember / Forget NEW

跨会话持久记忆。user/feedback/project/reference 四类。MEMORY.md 索引自动维护。

rememberforget.anima/memory/

🎭 Output Style NEW

可选输出风格：default（标准）、explanatory（解释性）、learning（协作模式）、concise（精简模式）。

/styleOutputStyle

🔧 内置技能 NEW

4 个 subagent 技能：explore（代码探索）、research（代码+网页研究）、review（代码审查）、security_review（安全审查）。

exploreresearchreviewsecurity_review

v0.15.1 增量 — 技能下载 + MCP HTTP 传输

📥 install_source NEW

从 URL/GitHub/本地/.mcp.json 下载安装技能。两阶段：apply=false 返回计划，apply=true 执行。支持 op=uninstall 卸载。

Streamable HTTP: type="http"/"sse"。JSON-RPC 2.0 over POST，Mcp-Session-Id 管理。prompts/list 自动映射为 slash 命令。

HttpMcpConnectionSSEMcpPrompt

使用示例

// 调用内置 explore 技能探索代码库
run_skill({ name: "explore", arguments: "找到所有调用 AuthService 的地方" })

// 加载 inline 技能（plan-mode 可用）
read_skill({ name: "my-workflow" })

// 保存持久记忆
remember({ type: "project", description: "使用 JLine3 终端库", body: "项目使用 JLine3 3.26.1 实现终端UI..." })

// 向用户发起结构化提问
ask({ questions: [{ header: "框架", question: "选哪个框架？", options: [{ label: "React" }, { label: "Vue" }] }] })

// 切换输出风格
/style concise
